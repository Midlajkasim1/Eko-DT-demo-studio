The CCTV clips go here as .mp4 files (H.264, muted). They are licensed, so git ignores them: copy them onto each machine or server that runs the dashboard.
Every .mp4 here is offered in Equipment & Spaces > CCTV > Footage. By default cameras get V1 to V7 in order (CCTV_01 V1 ... CCTV_07 V7, CCTV_08 V1). A camera set to None counts as not recording.
